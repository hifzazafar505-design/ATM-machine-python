# 🏧 ATM Machine

A simple **console-based ATM Machine simulation built with Python**.

## 📌 Project Overview

This project simulates basic ATM operations through a menu-driven Python program.

## ✨ Features

* 🔐 PIN Check
* 💰 Balance Check
* 💵 Deposit Money
* 💸 Withdraw Money
* 🚪 Exit

## 🧠 Concepts Used

* Variables
* Input
* `while` loop
* `if-else` conditions
* Functions

## 🛠️ Technology

* Python 3

## ▶️ How to Run

Make sure Python 3 is installed.

Run:

```bash
python atm_machine.py
```

## 📋 Main Menu

The program provides the following options:

```text
1. PIN Check
2. Balance Check
3. Deposit
4. Withdraw
5. Exit
```
